# Regression Notes

**Read the notes here: https://janithramanayake523.github.io/Regression-Notes/**

These are course notes for an introductory regression course, covering the
background you need (probability review, intro statistics, linear algebra)
before moving into regression itself. Each topic is broken into its own
page with worked examples, step-by-step solutions, and short
"Check Your Understanding" questions (with answers you can reveal) so you
can test yourself as you go.

Currently covered:

- Review of random variables
- Review of introductory statistics (confidence intervals, hypothesis tests)
- Review of matrices and linear algebra
- Review of random vectors
- Glossary of terms used throughout

More units will be added as the course progresses, so check back for updates.
