How these notes are laid out (start here if you’re new)

If a lot of this material feels unfamiliar, or half-remembered from a previous course, that’s exactly who these notes are written for — every page mixes the formal definitions with plain-language intuition, worked numeric examples, and self-check questions, so you never have to sit with just a bare definition.

The road map for the Review material chapter

The four review sections build on each other in a specific order, all pointing toward one destination: being able to write down, estimate, and test a regression model.

In words: 1.1 gives you the probability vocabulary (expectation, variance, distributions) that 1.2 uses to build confidence intervals and hypothesis tests. Separately, 1.3 gives you the matrix algebra needed to handle many variables at once, which 1.4 uses to describe a whole dataset as a single random vector. Regression itself will combine both halves: it’s a hypothesis-testing problem (1.1–1.2) solved using matrix algebra (1.3–1.4).

Notation you’ll see throughout

A lot of the difficulty in a first pass through this material is really just difficulty with notation, not with the ideas themselves. Keep this table handy — it isn’t something to memorize up front, just something to glance back at whenever a symbol looks unfamiliar.

Symbol Read it as Means
\(X\) (capital) “the random variable X” An outcome that hasn’t happened yet / a rule for generating a number
\(x\) (lowercase) “a specific value x” One particular number \(X\) could turn out to equal
\(\Pr(\cdot)\) “the probability that…” A number between 0 and 1
\(\mathrm{E}[X]\) “the expectation/expected value/mean of X” The probability-weighted average of \(X\)
\(\mathrm{Var}[X]\) “the variance of X” The average squared distance of \(X\) from its mean
\(\mathrm{cov}[X,Y]\), \(\mathrm{corr}[X,Y]\) “the covariance/correlation of X and Y” How strongly (and in what direction) \(X\) and \(Y\) move together
\(X\sim \mathcal{N}(\mu,\sigma^2)\) “X is distributed as…” \(X\) follows this particular named distribution
\(X\perp Y\) “X is independent of Y” Knowing \(X\) tells you nothing about \(Y\)
\(\bar X\) (a bar) “X bar” The sample average, computed from actual data
\(\hat\theta\) (a hat) “theta hat” An estimate of the unknown quantity \(\theta\), computed from data
\(\Sigma\) (capital sigma) “Sigma”, or “the covariance matrix” In 1.4 specifically, this denotes a covariance matrix — don’t confuse it with \(\sum\) (below), even though they’re drawn almost identically!
\(\sum_{i=1}^n\) “the sum from i=1 to n” Add up whatever comes after it, for each value of \(i\) from 1 to \(n\)
WarningCommon mix-up: Σ the letter vs. Σ the sum

\(\Sigma\) (a covariance matrix, used starting in 1.4) and \(\sum\) (the summation symbol used everywhere) are typeset almost identically and easy to confuse at a glance. Context is really the only way to tell them apart: if it’s followed by “\(_{i=1}^n\) (something)\(_i\)”, it’s a sum; if it’s referred to as a matrix with rows/columns, it’s the covariance matrix.

What the colored boxes mean

Every page uses the same three box styles, so once you know the color code you can decide at a glance how carefully to read a given box:

TipBlue ‘Intuition’ boxes

These translate the formal definition just above into plain language and everyday examples. If a definition feels abstract, the intuition box right after it is where the “why” lives.

NoteWorked examples and definitions

Grey/neutral boxes are either formal content (definitions, theorems) or fully worked numeric examples you can follow step by step with a calculator.

WarningCommon mistakes

Yellow boxes flag a specific error that beginners very commonly make at that exact point in the material — worth pausing on, since these are the misunderstandings that tend to resurface later (often on a test).

Each page also ends with a Check Your Understanding section — short self-check questions with click-to-reveal answers. Try to answer each one yourself before revealing the answer; if you get one wrong, that’s useful information about which intuition box to reread, not a bad sign.
